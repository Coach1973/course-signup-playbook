完整版開工指令
第一次用、或這堂課有特別需求時用這版
我要做一頁「課程推廣報名網頁」。請照這一頁的流程和規格做：https://coach1973.github.io/course-signup-playbook/
這一次要一次交付三樣東西：①完整網頁 ②出圖清單（含 JSON）③ZIP 下載包。

【課程基本資料】
・課程名稱：【例如：女性個人 IP 打造 × AI 製作網頁和主題曲】
・一句話主張：【例如：早上找到你是誰，下午把你做出來】
・給誰上：【例如：離開職場半年以上、想重新出發的姊妹】
・日期與時間：【例如：12/30（三）09:00–18:00，一律寫具體時間，不寫「下午場」】
・地點：【場地名稱＋完整地址；線上課寫平台】
・費用：【原價／早鳥價／早鳥截止日；免費就寫免費；有政府補助也寫】
・名額：【例如：30 人，額滿為止】
・講師：【姓名、頭銜、照片、個人網頁或社群連結】
・主辦／協辦：【單位名稱與連結，沒有就寫「無」】
・報名後要做的事：【例如：匯款帳號、加入 LINE 群（附連結）、上課要帶手機】
・我有的素材：【講師照、上一場照片、影片、海報、學員心得…有幾個附幾個，沒有就寫「無」】
・參考連結：【主辦官網、上一場網頁、報導…】

【風格】【例如：陽光溫暖／深色質感／優雅沙龍；沒有就寫「照課程調性自選」】
【想用的特效】【從這一頁技法庫點名，例如「A 互動闖關＋第 9 招滾輪數字」；沒有就寫「你挑 2～3 招最適合的」】

【網頁要有這些區塊】（依序，內容依課程調整，用不到的可以省略並說明）
1. 固定頂部列：課程名＋「立即報名」按鈕一直看得到；手機收成漢堡選單，報名按鈕放在選單最下面
2. 開場主視覺：課程名、一句話主張、日期時間、地點、費用、兩顆按鈕（立即報名／看課程內容）、倒數計時
3. 痛點共鳴：「你是不是也……」三到六張卡，讓對象看到自己
4. 你會帶走什麼：具體成果，能用數字就用數字
5. 課程流程：時間軸，一段一段寫清楚幾點做什麼
6. 講師介紹：照片、頭銜、三個亮點、連到講師個人網頁
7. 上一場花絮與學員心得：有素材才做，沒有就省略，不要捏造
8. 場次與票價：早鳥、原價、名額、截止日；多場次用卡片並排讓人選
9. 地點與交通：地址、Google 地圖連結、停車或大眾運輸
10. 常見問題：可展開收合，至少五題
11. 轉傳區：一張直式、一張橫式海報（走出圖清單），加上分享按鈕和一句好轉傳的文案
12. 報名表單：姓名、手機、Email、場次（多場才放）、同行人數、從哪裡知道這堂課、備註；送出後顯示成功畫面和下一步（匯款資訊、LINE 群）
13. 固定頁尾

【報名表單規則】
・表單寫成 <form data-works-form="這次的網址代號">，欄位用一般的 name 屬性，送出鈕是真的 submit 按鈕
・不要自己寫送到別的伺服器的程式，也不要寫死任何 API 網址或金鑰；上架到 event.bymyway.com 時，系統會自動接上「送出就通知」
・送出成功畫面、必填檢查、手機號碼格式檢查要做好；電腦和手機都要真的按一次送出，看到成功畫面

【字級】全頁最小的字不能低於 20px，包括手機版、導覽、按鈕、表單欄位、提示文字、圖說、頁尾。以瀏覽器實際算出來的字級為準，不是只看 CSS

【網頁底部固定要加】
1. 本網頁由 TAVA AI 製作（連結：https://www.tava-ai.com/）
2. 出品人 大樹教練（連結：https://www.bymyway.com/）
3. 友善連結 榮樹下（連結：https://event.bymyway.com/curated/rongtree/）
4. 顧問師天團・人才軍火庫（連結：https://event.bymyway.com/curated/skyteam/）

【配圖規則】（最高優先：這個對話裡，你一張圖都不准自己出）
・有真實照片的位置，一律用我給的真實照片
・沒有照片、需要插畫、情境圖、海報的位置，不要自己畫。你只要把網頁做好，並在每個需要圖的位置寫一條出圖指令，整理成「出圖清單」；圖由我交給小龍蝦用 LK888 出
・任何情況下，都不准使用你內建或平台附帶的生圖功能，也不准找替代管道、委派其他工具代畫，連「先畫一張試試看」都不行。我說「把圖做出來」「全部都畫」，意思是替每張圖寫好指令，不是叫你畫
・不需要、也不要向我要任何 LK888 金鑰
・出圖清單每張圖要有：ID（IMG-001 起，不跳號）、對應網頁哪個區塊、類型（實景修飾／概念／圖解背景）、比例（16:9、4:3、4:5、1:1 擇一）、參考照片檔名（沒有就寫「無」）、英文指令（一整段、自成一體、圖裡不放文字、數字、浮水印、商標）、一句中文說明。清單開頭寫「總共 N 張」，N 等於實際筆數
・出圖清單做成 ZIP 裡的 prompts.html：每條可以單獨複製、整份可以一鍵複製；最後把整份 JSON 陣列（欄位 id、file、section、type、ratio、ref、prompt、caption、alt）原樣放在一個 <pre> 裡，另存一份 images.json
・海報上的課程名、日期、價格不要叫生圖畫字：生成圖只當背景，字由網頁排版疊上去
・網頁裡每一個要等出圖的位置，一律寫成 <img data-slot="IMG-001" src="（暫時圖）" alt="（一句話描述）">：編號跟出圖清單一致，一個位置一個編號。暫時圖放真實照片或清楚標示的示意圖（不留灰色空框），不要另外加「待換圖」字卡。圖出好之後，我會用工具照編號直接換進已上架的網頁
・做完網頁和清單就停下來，不用等圖傳回來
・回報時要說實話：沒有實際查過，不准說「沒有扣點」或「免費」；萬一已經出了圖，馬上告訴我出了幾張

【製作規則】
・文字和圖片一打開就全部顯示，不要做「捲動到才出現」才看得到的內容；捲動特效只能加分，不能是唯一的顯示方式
・圖片用一般的 <img src>，不要寫「先藏起來、載完才插進畫面」的載圖程式
・body 不要加 overflow-x:hidden（會讓固定頂部列失效），要防止左右晃改用 overflow-x:clip 或修好太寬的元素
・漸層或照片上的字要夠清楚：深底配淺字、淺底配深字，對比不夠就加一層半透明底
・倒數計時要處理「活動已開始／已結束」的狀態，不能倒數成負數；日期要配對正確的星期幾
・新功能、主要按鈕要在第一屏就看得到，不要藏在最底下
・每個區塊都要有圖，不要整段只有文字

【EDM 規則｜只有我要求做 EDM 時適用，一律照做】
・EDM 裡一定要放圖片，直式、橫式都一樣：用這次出圖清單裡的主視覺圖（沒有合適的就放我給的原始照片），不准交純文字排版的 EDM
・圖還沒出好的時候，EDM 先放暫時圖；圖回填之後，EDM 要用新圖重做、重新輸出，不能只換網頁
・EDM 成品一律輸出成 JPG 或 PDF（直式、橫式各一張 JPG；要列印或轉寄再給一份 PDF），不單獨交 HTML 或 webp
・照片裡的人臉不能被文字、日期章、色塊或深色漸層蓋住，版面要讓人臉完整露出；照片優先用明亮、原樣的呈現，不要壓暗
・輸出後先自己打開成品檔，親眼確認圖有放進去、字沒被圖蓋住、人臉完整可見、地點日期是最新的，才能交付
・EDM 的 JPG／PDF 一起放進 ZIP 的 edm/ 資料夾

【交付方式】
・每張圖放進網頁前先壓縮：長邊 1000px、webp 品質約 72（單張約 100KB 上下）；圖片放在 images/ 資料夾，用相對路徑
・完成後打包成 ZIP 讓我下載（含網頁、prompts.html、images.json、圖片、我給的原始照片）
・【ZIP 上架規則｜強制】
  - 首頁檔名必須是全小寫的 index.html，直接放在 ZIP 根目錄，不得多包一層專案資料夾
  - index.html 必須是完整網頁內容，不得是空白頁、轉址頁或指向製作環境的連結
  - 網站可直接放上靜態主機，不需安裝套件、不需建置、不需後端
  - ZIP 裡不得有帳密、金鑰、登入設定、隱藏的執行目錄或其他私人資料
・【驗證對象是最後交付的 ZIP】打包後先列出 ZIP 內容，再解壓到全新資料夾，用瀏覽器開啟解壓出來的首頁，檢查電腦版與手機版的圖片、導覽、倒數、表單送出、FAQ 展開、分享按鈕，沒有破圖、缺資源或程式錯誤。任何一項沒過，修好、重新打包、重新驗證，才能交付
・交付時要分清楚「已通過本地解壓與瀏覽器驗證」和「已成功上架」；沒拿到上架成功的結果，不准說上架成功
・查不到或互相矛盾的資料（日期、價格、地址、講師頭銜），不要自己猜，最後列出來給我確認
・最後一段只寫三件事：網頁在哪、出圖清單在哪、ZIP 在哪，再加上要我另外交給小龍蝦的參考照片

STEP 4 · 製作經驗

做這 17 頁學到的事

每一條都是真的改過、被教練糾正過才寫進來的。照這些原則做，可以少改好幾輪。

🧭

進度列要固定在最上方

「從 A 到 B」第一版把關卡地圖放在開場下面，往下滑就看不到了。教練要的是固定在最上方的 A→B 進度列：數字一關一關亮起，點 ☰ 才展開關卡名稱。導覽、進度、報名按鈕都要「一直看得到」。（2026-11-08）

⬜

不要寫「載完才插進畫面」的載圖程式

TAVA 做的網頁常把圖片先藏起來、等載完再插進畫面，結果離畫面遠的圖永遠不會載，整區空白。一律用一般的 <img src>，最多加 loading="lazy"，不要另外寫載圖程式。（2026-11-03、11-05 兩次）

📌

body 加 overflow-x:hidden，固定頂部列就壞了

為了防止手機左右晃，在 body 加了 overflow-x:hidden，固定頂部列就跟著滑掉。改用 overflow-x:clip，或直接找出太寬的元素修好。（2026-10-25 全站查過 84 頁）

🌓

漸層和照片上的字要量對比

深色區塊的字顏色連續改錯三次，因為漸層背景用程式量會漏掉。交付前要截圖量真實像素，看不清楚就加一層半透明底。（2026-11-01、11-04）

☑️

表單一定要有真的送出鈕

有一頁做了勾選清單卻沒有送出鈕，教練勾了 35 項只能口述。任何要人填的東西，都要有送出鈕和成功畫面，交付前自己填一次、按一次。（2026-10-24）

👀

重要的東西放第一屏

新功能放在頁面中段，教練沒滑到就等於沒看到。主要按鈕、倒數、新加的功能，打開網頁不用捲就要看得到。（2026-10-24）

🔠

字級從第一版就做到 20px

表單提示字、頁尾、按鈕、時間軸小標最容易漏。不要等做完才放大，一開始就用 20px 當最小字，交付前用瀏覽器量電腦版和手機版。

🖼️

EDM 一定要放圖，直式橫式都一樣

ai-image1202 第一版 EDM 是純文字排版，一張圖都沒有，教練說「沒有圖片也叫 EDM？」。主視覺圖要放進 EDM；圖回填後 EDM 也要用新圖重做，不能只換網頁。

🙈

人臉不能被蓋住：日期牌、深色漸層都不行

網頁封面的「12.02 星期三 下午」日期牌壓在人物額頭和眼睛上；EDM 又用深色漸層把照片壓得烏漆麻黑。照片要明亮、原樣呈現，日期牌放在身體或空白區（手機版排到照片下方）。做完先自己看一眼臉有沒有被蓋，再交付。

📄

EDM 成品一律輸出 JPG 或 PDF

只給 webp 或 HTML，教練拿去轉傳、列印都不方便。直式、橫式各一張 JPG，要列印轉寄再給一份 PDF，放在 ZIP 的 edm/ 資料夾。

🧑‍🏫

講師是大樹教練，就直接複製最近一頁的講師卡

不要寫「講師資訊即將公布」。照最近做的網頁（例如婦女再就業頁的 #speakers）把大樹教練的照片、27 年／6,000+ 場／10 萬+ 人次、資歷條列複製過來，配色換成這一頁自己的。簡介裡跟這堂課無關的細節（例如「只用手機」）要拿掉。

📮

報名表單常是假送出，上架後要接到後台

TAVA 做的報名頁常只是「按送出就跳成功畫面」，資料根本沒進後台。上架後要確認表單真的送進報名系統、活動資料列已建好，實測一筆再把測試資料清掉。

🎨

一張圖都不准自己出

曾有 AI 收到「把圖做出來」就自己畫了很多張，額外扣了很多點數。生圖一律只寫出圖清單，交給小龍蝦用 LK888 出；位置寫成 data-slot 編號，圖出好可以直接換進線上網頁。

🕐

時間一律寫具體

寫「14:00–16:30」，不寫「下午場」「晚上」。日期後面的星期幾要核對過，倒數計時也要用同一個時間。

💌

好轉傳比好看重要

報名多半是朋友轉傳來的。直式海報給 LINE、橫式給 FB，加一句可以直接貼的文案，比再多一個特效有用。

💰

錢的事寫最清楚

費用、早鳥截止、補助怎麼領、匯款帳號、退費規定，在票價區和常見問題各寫一次。看不懂錢的人不會報名。

🔁

同一頁可以變回顧頁

活動結束後不用另做一頁：把報名區換成影片、照片、歌曲和心法，學員回家還會再打開，下一場的口碑也從這裡來。

📦

ZIP 根目錄一定要有 index.html

首頁叫別的名字、或多包一層資料夾，上架系統就找不到首頁、整包失敗。驗證的是「最後交付的那個 ZIP」：解壓到新資料夾、用瀏覽器打開，通過才交付。

❓

查不到就列出來，不要猜

日期、價格、地址、講師頭銜只要有一處不確定，就照實寫並列成清單請教練確認。寫錯一個日期，比少一個特效嚴重得多。

STEP 6 · 交付前檢查

交付前逐項打勾

  • 課程名、日期、星期幾、時間、地點、費用、名額都核對過，時間寫具體（14:00–16:30）
  • 立即報名按鈕在第一屏看得到，捲到哪裡都找得到（固定頂部列或手機選單）
  • 倒數計時在活動開始、結束後顯示正確，不會變成負數
  • 表單真的按過送出：必填、手機格式檢查有效，成功畫面寫清楚下一步
  • 表單是 <form data-works-form="網址代號">，沒有寫死其他伺服器網址或金鑰
  • 常見問題可以展開收合，至少五題，錢和時間的問題都有回答
  • 地圖、講師、主辦、LINE 群、分享等連結都點過，打得開
  • 電腦版和手機版逐段量過字級，沒有小於 20px 的字（含按鈕、表單、頁尾）
  • 不捲動、直接打開時每個區塊都看得到文字和圖，沒有大片空白
  • 漸層、照片上的字對比夠，深底淺字、淺底深字
  • body 沒有 overflow-x:hidden，固定頂部列往下捲仍在
  • 人物照片上的臉完整看得到：沒有日期牌、倒數、文字、色塊或深色漸層壓在臉上（電腦版、手機版都看過）
  • 如果有 EDM：直式、橫式都放了圖，輸出成 JPG 或 PDF，自己打開看過有圖、臉沒被蓋、地點日期是最新的
  • 講師區不是「即將公布」：講師是大樹教練就複製最近一頁的講師卡，資料與照片都放上去了
  • 報名表單送出後，資料真的進了報名系統（實測一筆、清掉測試資料），不是只跳成功畫面
  • 每張圖都壓成長邊 1000px、webp 品質約 72，放在 images/ 用相對路徑
  • 沒有任何一張圖是 AI 自己生成的；出圖清單 prompts.html＋images.json 都在 ZIP 裡，總共 N 張等於實際筆數
  • 每個出圖位置都寫成 <img data-slot="IMG-編號">，編號跟清單一致，沒有「待換圖」字卡
  • 頁尾有 TAVA AI、大樹教練、榮樹下、顧問師天團・人才軍火庫四個連結
  • ZIP 根目錄有全小寫、非空白的 index.html，沒有多包一層資料夾，不含帳密或金鑰
  • 已把最後交付的 ZIP 解壓到新資料夾，用瀏覽器打開包內首頁檢查過電腦版和手機版
  • 回報時分清楚「已通過本地驗證」和「已成功上架」，查不到的資料列成清單請教練確認

展開：課程推廣報名網頁技能規格

觸發

使用者說「做一頁課程報名網頁」「做活動報名頁」「課程推廣網頁」「照課程推廣報名網頁流程」，並附上課程資料。資料齊全就直接開工，不必再問要不要做；缺的資料用合理暫填並在交付時列出。

一次交付三樣（缺一不算完成）

  • index.html：單一完整網頁，依上方 13 個區塊，素材放 images/。
  • prompts.html＋images.json：出圖清單。開頭寫「總共 N 張」；每條欄位 id、file、section、type（實景修飾／概念／圖解背景）、ratio（16:9／4:3／4:5／1:1）、ref、prompt（英文、自成一體、無文字）、caption、alt；整份 JSON 陣列原樣放在一個 <pre> 裡，另存 images.json。每條可單獨複製，整份可一鍵複製。
  • ZIP：根目錄 index.html（全小寫）、prompts.html、images.json、images/、原始照片；不多包資料夾、不含任何秘密。

硬規格

  • 所有可見文字（含手機、導覽、按鈕、表單、提示、圖說、頁尾、出圖清單頁）以瀏覽器計算字級 ≥ 20px；內文約 22px。
  • 絕不自行生成圖片（內建生圖、外部工具、委派都不行）；需要圖的位置寫 <img data-slot="IMG-NNN" src="暫時圖" alt="…">，暫時圖用真實照片或清楚標示的示意圖。
  • 表單：<form data-works-form="網址代號">，一般 name 欄位、真的 submit 按鈕、前端必填與手機格式檢查、成功畫面含下一步；不寫外部 API、不放金鑰。
  • 不做唯一靠捲動觸發的顯示；不寫延遲插入圖片的載圖程式；body 不用 overflow-x:hidden；漸層與照片上的文字確保對比。
